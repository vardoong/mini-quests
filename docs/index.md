## 문서 확인 방법

1. 필요시 가상환경 사용

    ```shell
    python3 -m venv .venv
    source .venv/bin/activate
    ```

2. 의존성 설치

    ```shell
    pip install mkdocs mkdocs-material
    ```

3. 실행

    ```shell
    mkdocs serve
    ```
